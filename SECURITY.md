# Security policy

## Supported versions

Sharingan is pre-1.0: only the latest code on `main` (and the registry served from the website) receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.
Report it privately through GitHub: **Security → Report a vulnerability** on [rasengan-dev/sharingan](https://github.com/rasengan-dev/sharingan/security/advisories/new).

Include what is affected (a hero, the core, the registry, the website), how to reproduce it, and its impact.
You will get an answer within a week. Once a fix is out, the advisory is published with credit to you, unless you prefer otherwise.

Heroes are copied into your project as source code: after a fix, update a hero by running `npx shadcn@latest add @sharingan/<name>` again.
